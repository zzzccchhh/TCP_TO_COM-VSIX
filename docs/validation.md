## 已知边界

1. 尚未连接真实 ESP、实际 USB 或业务 COM；自动化使用串口模拟与本机 sockets，不能证明电平、硬件流控、实际复位或 5 Mbps 吞吐。
2. Windows DSR/DTR 与 DTR/RTS 状态通过固定版本串口 binding 的句柄和系统 DCB 补充设置。已验证原生库在实际扩展宿主加载、标志位映射及错误处理；打开串口时的瞬态电平仍需示波器／实机确认。
3. Windows Keepalive 由插件内原生补充模块通过当前事件循环内的精确 TCP 端点匹配后设置；当前系统已验证空闲时间、探测间隔与次数设置成功。旧系统不支持次数选项时保留系统策略，与旧程序的 Windows 边界一致。
4. 串口使用事件流，保留读取 timeout 字段用于旧设置兼容，不以 Python 的定时阻塞读取方式执行。写入超时仍显式处理。
5. 手机连接、在线 HTTPS 网页到局域网 HTTP 的浏览器权限、系统防火墙、真实 DHCP／网卡断开恢复和多进程异常退出仍需现场验证。
6. Windows x64 包已作为首个目标；其他操作系统／架构未验收。
